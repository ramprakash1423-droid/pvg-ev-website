# PVG-EV Asset Library

Reusable PVG-EV website imagery lives here. Use these files before adding any outside image source.

## Structure

- `branding/` - PVG-EV logo variants and favicon.
- `hero/` - large page hero images, optimized at 2560 x 1440.
- `vehicles/` - official mobile charging van views and fleet lineups.
- `chargers/` - official charging station, display, plug, and cable visuals.
- `engineers/` - PVG-EV engineer and support-team imagery.
- `fleet/` - fleet depot, logistics, bus, and charging-depot scenes.
- `apartment/` - residential, apartment, community, and villa charging scenes.
- `commercial/` - office, mall, hotel, hospital, retail, factory, and tech-park charging scenes.
- `contact/` - consultation, support, and contact hero visuals.
- `maps/` - Tamil Nadu, Chennai, coverage, and expansion map assets.
- `backgrounds/` - Chennai, OMR, ECR, Marina, TIDEL Park, industrial, and night skyline backgrounds.
- `icons/` - raster icon previews. Prefer inline SVG/CSS icons in UI where possible.

## Usage

Keep the PVG-EV van, charger, engineer uniform, green-blue lighting, and Chennai/South India context consistent across pages. Do not use random stock photos or third-party branded charging stations.
